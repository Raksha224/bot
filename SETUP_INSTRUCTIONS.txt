ELECTRICIAN CHATBOT - SETUP INSTRUCTIONS
==========================================

QUICK START (5 MINUTES)
=======================

1. INSTALL SOFTWARE
   - Python: https://python.org/downloads (check "Add to PATH")
   - Ollama: https://ollama.com/download

2. DOWNLOAD FILES
   - Download all files to a folder
   - Open Command Prompt in that folder

3. INSTALL DEPENDENCIES
   pip install -r requirements.txt

4. DOWNLOAD AI MODEL
   ollama pull mistral

5. START CHATBOT
   Windows: Double-click setup.bat
   Mac/Linux: Run ./setup.sh

6. OPEN IN BROWSER
   Go to: http://localhost:5000

DETAILED STEPS
==============

STEP 1: INSTALL PYTHON
----------------------
Windows:
1. Go to https://python.org/downloads
2. Download Python 3.8 or newer
3. Run installer
4. IMPORTANT: Check "Add Python to PATH"
5. Click "Install Now"

Verify: Open Command Prompt, type "python --version"

Mac:
- brew install python
- Or download from python.org

Linux:
- sudo apt install python3 python3-pip (Ubuntu/Debian)
- sudo yum install python3 python3-pip (CentOS/RHEL)

STEP 2: INSTALL OLLAMA
----------------------
Windows:
1. Go to https://ollama.com/download
2. Download Windows installer
3. Run installer
4. Restart Command Prompt

Mac/Linux:
curl -fsSL https://ollama.com/install.sh | sh

Verify: Open Command Prompt, type "ollama --version"

STEP 3: DOWNLOAD CHATBOT FILES
------------------------------
Create folder "electrician-chatbot" and download:
- app.py
- requirements.txt
- templates/index.html
- templates/bookings.html
- setup.bat (Windows)
- setup.sh (Mac/Linux)

STEP 4: INSTALL PYTHON DEPENDENCIES
-----------------------------------
Open Command Prompt in chatbot folder:
pip install -r requirements.txt

If permission error:
pip install --user -r requirements.txt

STEP 5: DOWNLOAD AI MODEL
-------------------------
ollama pull mistral

Alternative models:
ollama pull llama3    # Alternative
ollama pull phi3      # Smaller, faster

STEP 6: START THE SYSTEM
------------------------
Method 1 (Automatic):
- Windows: Double-click setup.bat
- Mac/Linux: Run ./setup.sh

Method 2 (Manual):
Terminal 1: ollama serve
Terminal 2: python app.py

STEP 7: ACCESS CHATBOT
----------------------
Open web browser:
- Customer Interface: http://localhost:5000
- Admin Dashboard: http://localhost:5000/bookings

TROUBLESHOOTING
===============

"Python not found"
- Reinstall Python with "Add to PATH" checked
- Or add Python to PATH manually

"Ollama not found"
- Reinstall Ollama
- Restart Command Prompt

"Module not found"
- pip install flask requests

"Port 5000 already in use"
- Close other applications
- Or change port in app.py

"Ollama connection failed"
- Make sure Ollama is running: ollama serve
- Wait 30 seconds after starting
- Check model: ollama list

Chatbot shows errors
- Make sure Ollama is running
- Make sure Mistral model is downloaded
- Restart both Ollama and chatbot
